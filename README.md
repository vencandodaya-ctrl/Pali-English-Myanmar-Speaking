# ပါဠိ + အင်္ဂလိပ် + မြန်မာ စကားပြော App

ပါဠိ၊ အင်္ဂလိပ် နှင့် မြန်မာ စကားပြော/ဝါကျများကို လွယ်ကူစွာ လေ့လာနိုင်ရန် ဖန်တီးထားသော Progressive Web Application (PWA) ဖြစ်ပါသည်။

## Features
*  ပါဠိ၊ Roman Pli၊ အင်္ဂလိပ် နှင့် မြန်မာ ဝါကျ ၄၄၇ စာကြောင်း ပါဝင်ခြင်း
*  အမြန် ရှာဖွေနိုင်သည့် စနစ် (Search)
*  အခန်းအလိုက် ကြည့်ရှုနိုင်သည့် မာတိကာ (Table of Contents)
*  အကြိုက်ဆုံး ဝါကျများကို သိမ်းဆည်းနိုင်ခြင်း (Favorites)
*  Roman Pli အသံထွက် နားထောင်နိုင်ခြင်း (Text-to-Speech)
*  Day / Night Mode ပြောင်းလဲအသုံးပြုနိုင်ခြင်း
*  PWA Support ပါဝင်သဖြင့် Web App အဖြစ်လည်းကောင်း၊ Native App ကဲ့သို့လည်းကောင်း အသုံးပြုနိုင်ခြင်း

## Tech Stack
* **HTML5** / **CSS3** (Responsive & Mobile-first design)
* **JavaScript** (Vanilla JS, Service Worker)
* **PWA** (Web App Manifest + Offline Caching)
